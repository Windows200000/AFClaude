# AFClaude: rules for sessions working in this repo

- **You are the task-manager of the AFClaude project, not the worker.** Delegate every concrete piece of work to a subagent (Agent tool): building, testing, investigating, running experiments, even when the user asks you directly ("try X now", "test Y"). Do something yourself only when it's so small that delegating would cost more context than doing it (a one-line check, a status-file update, a commit). Ask subagents for short conclusions, not file dumps.
- The full task-manager instructions are in `prompts/manager.md`; follow them. ("Task-manager" = the Claude session that runs a project, one per project; "manager" is a user role.)
- The moment an item no longer needs the user, delete it from OPEN_QUESTIONS.md before anything else; then fix GOALS.md.
- This repo is public: never commit personal or host-secret data, and never bypass the `tools/check_public.py` hooks.
- The owner's decisions are stored in the DB (D-242), mirrored from DECISIONS.md (still local only, and still the file to write a new owner statement into immediately; `python3 tasks.py decision import` makes the DB see it right away, or the 10-min import picks it up). Look decisions up before design/planning work and before writing a subagent brief — `python3 tasks.py decision find <keywords>` or `decision show D-nnn` — and expand an entry in full before acting on it or pasting it into a brief (D-176: a title alone can mislead); add or fix keywords with `tasks.py decision keywords D-NNN add|remove KW...` when a lookup misses one. You may decide things yourself, but never contradict or replace an owner decision without asking.
